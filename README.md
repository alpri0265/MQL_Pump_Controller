# MQL 2004 I2C Encoder V2

Система управления насосом СОЖ (смазочно-охлаждающей жидкостью) для станков ЧПУ с LCD-дисплеем 2004, энкодером KY-040 и драйвером шагового двигателя DM556.

## 🔧 Требования

### Аппаратное обеспечение:
- **Arduino Uno/Nano** (или совместимая плата)
- **LCD дисплей 2004 I2C** (адрес 0x27 или 0x3F)
- **Энкодер KY-040**
- **Драйвер шагового двигателя DM556**
- **Потенциометр** 10 кОм
- **Кнопка START/STOP** с LED индикатором
- **Шаговый двигатель** (подключен через DM556)

### Программное обеспечение:
- **Arduino IDE** (версия 1.8.x или выше) или **PlatformIO**
- **Библиотека LiquidCrystal_I2C** (для работы с LCD)

## 📦 Установка

### 1. Установка Arduino IDE
Скачайте и установите [Arduino IDE](https://www.arduino.cc/en/software) если ещё не установлена.

### 2. Установка библиотеки LiquidCrystal_I2C

**Способ 1 (через менеджер библиотек):**
1. Откройте Arduino IDE
2. Перейдите в `Скетч` → `Подключить библиотеку` → `Управлять библиотеками...`
3. Найдите `LiquidCrystal_I2C`
4. Установите версию от **Frank de Brabander**

**Способ 2 (вручную):**

1. Откройте файл `mql_2004_I2C_encoder_V2/mql_2004_I2C_encoder_V2.ino` в Arduino IDE
2. Все остальные файлы проекта (.h и .cpp) должны находиться в той же папке

## 🔌 Подключение оборудования

### LCD 2004 I2C:
- **VCC** → 5V
- **GND** → GND
- **SDA** → A4 (Arduino Uno/Nano) или SDA (другие платы)
- **SCL** → A5 (Arduino Uno/Nano) или SCL (другие платы)

### Энкодер KY-040:
- **CLK (S1)** → **D2** (PIN_BTN_UP)
- **DT (S2)** → **D3** (PIN_BTN_DOWN)
- **SW (BTN)** → **A3** (PIN_BTN_OK)
- **+** → 5V
- **GND** → GND

### Потенциометр:
- **Средний вывод** → **A0** (PIN_POT)
- **Один край** → 5V
- **Другой край** → GND

### Кнопка START/STOP:
- **Один вывод** → **A1** (PIN_START_BTN)
- **Другой вывод** → GND
- **LED анод** → **A2** (PIN_START_LED)
- **LED катод** → GND (через резистор 220-330 Ом)

### Драйвер DM556:
- **PUL+** → **D12** (PIN_STEP)
- **DIR+** → **D10** (PIN_DIR)
- **ENA+** → **D11** (PIN_ENA)
- **PUL-**, **DIR-**, **ENA-** → GND
- **Подключите шаговый двигатель** к выходам драйвера
- **Питание драйвера** подключите согласно спецификации DM556

## ⚙️ Настройка

### Настройка адреса LCD
Откройте файл `config.h` и проверьте адрес I2C:

```cpp
constexpr uint8_t LCD_I2C_ADDR = 0x27;   // поменяй на 0x3F если у тебя так
```

**Как определить адрес:**
1. Загрузите пример `I2C Scanner` из Arduino IDE
2. Подключите LCD и запустите сканер
3. Скопируйте найденный адрес в `config.h`

### Настройка энкодера

В файле `config.h` можно настроить:

```cpp
// Количество переходов на один "щелчок" энкодера
constexpr uint8_t ENC_DETENT_EDGES = 4;  // 4 = KY-040, 2 = некоторые EC11

// Инверсия направления
constexpr bool ENC_INVERT_DIR = true;    // false = прямое, true = обратное

// Защита от дребезга
constexpr uint16_t ENC_MIN_EDGE_US = 300; // микросекунды
```

### Настройка языка интерфейса

В файле `config.h`:

```cpp
#define UI_LANG UI_LANG_EN  // Английский
// или
#define UI_LANG UI_LANG_UA  // Украинский
```

## 🎮 Использование

### Основные режимы:

1. **READY (Готов)** — начальный экран
   - **START** → запуск насоса
   - **Короткое нажатие OK** → меню настроек
   - **Длительное нажатие OK** → мастер настройки (Wizard)

2. **RUN (Работа)** — режим работы насоса
   - **Потенциометр** → регулировка расхода
   - **START** → остановка

3. **MENU (Меню)** — настройки системы
   - **Энкодер** → навигация
   - **OK** → выбор/редактирование
   - **Длительное нажатие OK** → отмена/выход
   - **START** → выход в READY

4. **Wizard** — быстрая настройка
   - Выбор материала (Steel/Aluminum)
   - Выбор диаметра фрезы (3-50 мм)
   - Рекомендация расхода

### Калибровка насоса:

1. Зайдите в меню настроек
2. Выберите пункт калибровки
3. Выберите время калибровки (60 или 120 секунд)
4. После окончания введите измеренный объём СОЖ
5. Система автоматически рассчитает коэффициент

### Тест LCD:

В меню есть пункт "LCD Test" для проверки отображения всех символов.

## 🐛 Решение проблем

### LCD не работает:
- Проверьте адрес I2C в `config.h`
- Проверьте подключение SDA/SCL
- Проверьте питание 5V

### Энкодер работает неправильно:
- Попробуйте изменить `ENC_INVERT_DIR` в `config.h`
- Проверьте подключение CLK и DT (может потребоваться поменять местами)
- Увеличьте `ENC_MIN_EDGE_US` если есть "фантомные" шаги

### Насос не запускается:
- Проверьте подключение DM556
- Проверьте питание драйвера
- Проверьте настройки `pump_gain_steps_per_u_min` в меню

### Кнопка START не реагирует:
- Проверьте подключение к A1
- Убедитесь, что кнопка подключена к GND при нажатии
